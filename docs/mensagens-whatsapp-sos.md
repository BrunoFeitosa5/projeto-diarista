# Mensagens do S.O.S Diaristas (WhatsApp comum, pelo WhatsApp Web)

Número das diaristas: (11) 91159-3485. É um **WhatsApp comum, atendido pelo
WhatsApp Web** (decisão do usuário, 23/10/2026): **não há atalhos com `/`,
saudação nem ausência automáticas**. Isso só existe no **WhatsApp Business dos
clientes** (final 2436, `mensagens-whatsapp.md`). Aqui a dona **copia e cola**
os textos abaixo, na ordem; os nomes com barra (`/grupo`, `/vaga`...) são só
rótulos.

O botão "Quero ser diarista" do site abre este chat com uma mensagem pronta
(nome, telefone e nascimento). A dona manda a primeira mensagem abaixo à mão e pede os dados; o
link do grupo só sai depois da conferência (texto `/grupo`). **O link do grupo fica só nestas mensagens do WhatsApp, nunca
no código nem no git.**

## Regras
- Diaristas trabalham seg a dom, das 8h às 17h. Atendimento: 6h às 21h.
- Repasse fixo por plano: 4h = R$ 100, 6h = R$ 120, 8h = R$ 160.
- O valor de cada serviço é combinado no privado, nunca no grupo.
- No grupo vai só o aviso do pedido (código, data, plano, bairro e cidade),
  sem endereço, nome do cliente nem valor.
- Nunca pedir senha nem dados de cartão pelo chat.

## Primeira mensagem e ausência (enviadas à mão)

**Primeira mensagem** (ao responder a diarista que chamou pela primeira vez). **Não leva o
link do grupo**: a dona só envia o convite depois de conferir a diarista (`/grupo`):

```
Olá, tudo bem? 😊 Seja bem-vinda à Império Diarista!

Avisamos os serviços disponíveis em um grupo de vagas. Para entrar, a gente faz uma conferência rápida. Me envie por favor:
- Nome completo
- Bairro e cidade onde você mora
- Há quanto tempo trabalha como diarista
- Uma referência (nome e telefone de uma ex-patroa)

Depois da conferência, enviamos o convite do grupo por aqui. Se já estiver no grupo e tiver interesse em um serviço, é só chamar aqui com o código do pedido, por exemplo IMP-000123.
```

**Mensagem fora do horário** (se a dona responder de madrugada, das 21h às 6h):

```
Olá! Obrigada pelo contato com a Império Diarista. 😊

Nosso atendimento é todos os dias, das 6h às 21h. Deixe aqui seu nome e sua dúvida que respondemos assim que voltarmos!
```

## Avisos para o grupo das diaristas

A dona os envia **dentro do grupo** (WhatsApp Web), trocando o que está entre `[colchetes]`. Os dados vêm da mensagem do
cliente, que já chega com o código (`Pedido IMP-000123`). Nunca copiar o nome,
o telefone, o endereço nem o valor para o grupo.

**/vaga**

```
📢 Vaga disponível — [IMP-000123]
• Data: [dia, 25/10] às [horário]
• Plano: [6h]
• Local: [bairro, cidade]

Quem tiver interesse, chame o S.O.S Diaristas no privado, (11) 91159-3485, com o código [IMP-000123]. A primeira diarista verificada que chamar leva a vaga.
```

**/preenchida** (quando a dona escolher a diarista)

```
✅ [IMP-000123] já foi preenchida. Obrigada a todas! Seguimos avisando as próximas vagas aqui. 💜
```

Como decidir "a primeira": vale o horário da mensagem no privado do S.O.S. Se
a primeira não for verificada ou desistir, passa para a seguinte. Depois de
escolher, a dona manda `/confirmada` para ela, `/outra` para as demais que
chamaram e `/preenchida` no grupo. Endereço e valor só no privado.
